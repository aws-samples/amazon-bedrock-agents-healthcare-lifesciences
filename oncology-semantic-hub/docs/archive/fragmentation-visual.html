📄 The Literature Problem: Same Biology, Different Languages

Published papers use inconsistent ontologies, gene nomenclature, and data sources — making it nearly impossible to reproduce or combine findings computationally.

Example: Three papers studying TP53 in breast cancer

⚠️ All three papers study the SAME mutation in the SAME gene in the SAME cancer — but use completely different identifiers, ontologies, cohorts, and filtering criteria.

Why this makes hypothesis reproduction impossible without a semantic layer

🔤
Terminology mismatch
"Breast cancer" ≠ "invasive ductal carcinoma" ≠ "BRCA". A keyword search finds Paper A but misses B and C. Only ontology-aware search (MONDO hierarchy) connects them.
🧬
Gene ID fragmentation
Paper A says "TP53", Paper B says "ENSG00000141510", Paper C says "7157". Without a mapping table, you can't confirm they're discussing the same gene.
💊
Drug name ambiguity
"Alpelisib" = "BYL719" = "DB12015" = "Piqray" = ATC L01XX65. Five names for one drug. Literature uses all of them interchangeably.
📐
Variant representation
"R248W" vs "p.Arg248Trp" vs "chr17:7674220 C>T" — same mutation, three notations. Protein-level, HGVS, and genomic coordinates don't cross-reference without tools.
📊
Cohort incompatibility
TCGA, METABRIC, and MSK-IMPACT use different sequencing panels, mutation callers, and filtering thresholds. "TP53 mutated in 30%" means different things in each.
🏗️
Genome build drift
Paper A uses GRCh37, Papers B/C use GRCh38. Genomic coordinates shift between builds. chr17:7674220 in hg38 ≠ the same position in hg19.

✅ How the Semantic Hub solves this

• Ontology normalization: "breast cancer", "invasive ductal carcinoma", and "BRCA" all resolve to MONDO:0007254 via synonym matching and hierarchy traversal

• ID harmonization: TP53 = ENSG00000141510 = 7157 = P04637 — all pre-mapped on the gene node

• Drug resolution: Alpelisib = BYL719 = DB12015 = Piqray — all synonyms on the drug node

• Variant normalization: ClinVar maps protein, HGVS, and genomic notations to a single variant record

• Cohort-aware querying: Agent knows TCGA-BRCA has 1,098 cases and can compare to other cohorts in the data lake

Result: An agent can find ALL papers about TP53 R248W in breast cancer regardless of which nomenclature the authors used — and reproduce their findings against the same underlying data.
